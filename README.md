# Unity3d-TowerDefense
(Junior Year Game Project)Unity3D-based SLG Tower Defense Game Development

## Project Overview (项目简介)
This is a Tower Defense game developed using Unity, inspired by [Siki Academy](https://www.sikiedu.com/course/1885?ff=b_siki). The game has been enhanced with additional features and modified visuals.


### Modifications (改动)
参考：[siki学院](https://www.sikiedu.com/course/1885?ff=b_siki)

在siki的基础上改动：
 - Custom UI for the start and end screens. 
- Green color scheme (personal preference!).
- Added mountainous forest background.
- Added "Enemy Wave" UI display.
- Tweaked enemy and turret parameters (speed, damage, etc.).

**修改版本开源已征得原作者同意。**

## 三．关键代码

### 1. 敌人移动、掉血及死亡功能
**功能描述**  
- 初始化敌人位置和生命值，沿预设路径移动。
- 到达终点触发游戏失败 (`GameManager.Instance.Fail()`)。
- 受伤害时减少生命值，生命值 ≤0 时销毁敌人并播放爆炸效果。  

### 2. 敌人生成功能
**功能描述**  
- 按波次生成敌人，波次间隔 5 秒。
- 协程异步生成，确保当前波次敌人全灭后再生成下一波。
- 更新 UI 显示当前波次。  

### 3. 炮塔建造、升级和拆除功能
**功能描述**  
- `BuildManager`：单例模式管理建造/升级逻辑，判断金钱是否充足。
- `UpgradeUI`：控制升级/拆除界面的显示和操作。  

### 4. 炮塔自动瞄准和攻击敌人
**功能描述**  
- 通过触发器检测敌人进入攻击范围。
- 炮塔头部朝向目标敌人 (`LookAt`)。
- 按攻击频率发射子弹。  

### 5. 子弹追踪与伤害功能
**功能描述**  
- 子弹追踪目标 (`LookAt(target.position)`)。
- 近距离命中时调用 `Enemy.TakeDamage()`。
- 命中后播放爆炸效果并销毁。  

### 6. 激光炮塔攻击功能
**功能描述**  
- 继承 `Turret`，重写 `Attack` 方法。
- 使用 `LineRenderer` 绘制激光并持续造成伤害。  

### 7. 游戏结束界面功能
**功能描述**  
- `GameManager`：检测胜负状态，显示对应 UI（“WIN”/“GAME OVER”）。
- `GameEndUI`：控制结束界面的动画和按钮事件（重新开始/返回菜单）。  

### 8. 开始菜单功能
**功能描述**  
- “Play” 按钮加载场景 1 开始游戏。
- “Exit” 按钮调用 `Application.Quit()` 退出游戏。

## 五．总结
| 知识点         | 是否用到 | 应用描述                     |
| -------------- | -------- | ---------------------------- |
| Transform 类   | 是       | 摄像机移动、敌人路径控制     |
| Vector3 工具类 | 是       | 敌人移动路径计算             |
| Time 工具类    | 是       | 敌人移动速度计算             |
| Random 工具类  | 否       | (未开发随机敌人)             |
| 输入控制       | 是       | 摄像机移动和缩放             |
| 协程           | 是       | 敌人生成逻辑                 |
| 地形系统       | 是       | 森林场景搭建                 |
| 摄像机控制     | 是       | 玩家视角控制                 |
| Mecanim 动画   | 是       | 炮塔升级动画、金钱文本闪烁   |
| 碰撞检测       | 是       | 子弹击中敌人                 |
| 触发器         | 是       | 检测敌人进入炮塔攻击范围     |
| 射线           | 否       |                              |
| 粒子系统       | 是       | 爆炸、建造特效、激光效果     |
| UI 界面        | 是       | 炮塔选择/游戏菜单/结束界面   |
| 数据存储       | 是       | 游戏字体配置                 |
| 导航网格       | 否       |                              |
| **扩展技术**   |          |                              |
| 单例模式       | 是       | GameManager, BuildManager 等 |
| 对象实例化     | 是       | 动态生成敌人/子弹/特效       |
| LineRenderer   | 是       | 激光炮塔攻击效果             |
